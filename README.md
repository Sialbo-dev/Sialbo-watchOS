# Sialbo-watchOS

# 🕐 시얼보

### 시간표, 얼른 보자.

**시얼보**는 학교 시간표를 **Apple Watch에서 빠르게 확인할 수 있는 앱**입니다.

수업 중 휴대폰을 꺼내기 어려울 때도
손목을 한 번 확인하는 것만으로 **현재 수업과 다음 수업을 확인할 수 있도록** 만들었습니다.

<br>

## ✨ Why Sialbo?

매번 바뀌는 시간표를 직접 입력해야 하는 기존 시간표 앱은 번거롭습니다.

시얼보는 학생이 매일 사용하는 **학교 시간표를 손목에서 바로 확인하는 경험**에 집중합니다.

* ⌚️ Apple Watch에서 시간표를 빠르게 확인
* 📚 현재 수업과 다음 수업을 한눈에 확인
* 🔄 변경되는 학교 시간표를 편리하게 확인
* 🫳 작은 화면에서도 직관적으로 사용할 수 있는 UI

<br>

## 📱 Sialbo

> **"수업*중에도,*시간표는 손목에서."**

더 빠르고 자연스럽게 확인할 수 있는 방법을 고민하며 시작한 프로젝트입니다.
